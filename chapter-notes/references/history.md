# 历史章节笔记规范

历史章节笔记属于文科史料解释型结构，应围绕"时空定位、历史背景、过程线索、原因影响、史料解读、历史解释"展开，不要套用理科概念公式结构。

## Core Structure

在 `核心知识点讲解` 中使用以下内部结构：

```markdown
### 一、时空定位与阶段特征
### 二、历史背景与核心事件
### 三、发展过程与线索梳理
### 四、原因、影响与历史意义
### 五、史料解读与历史解释
### 六、比较迁移与考试表达
```

## 图片风格约束

历史配图统一使用克制的时间轴、地图与史料分析风格：浅米色或浅灰背景，黑灰文字和线条，暗红标出关键事件，深蓝标出制度/力量关系，棕色标出背景或阶段特征；优先使用时间轴、因果链条、人物/群体关系图、地图定位、制度结构图和史料信息提取框。图中不画夸张战争场面、写实人物肖像或戏剧化插画，重点呈现时空定位、过程线索、因果关系和影响评价。

## 必须突出

- 从时间、地点、人物/群体、事件和历史阶段开始。
- 分析原因时覆盖政治、经济、文化、社会、国际环境等维度。
- 影响评价按短期/长期、国内/国际、积极/消极等角度组织。
- 例题包含材料分析、比较、因果解释、历史意义和观点评价。
- 练习题包含时间轴、概念解释、材料解读、比较题和小论文式问答。
- `重点梳理` 要包含时间线、关键人物/群体、核心事件、背景、原因、影响和历史概念。
- `难点突破` 聚焦阶段特征、因果关系、史料立场、历史解释和比较分析。
- `例题讲解` 按"读材料 -> 定时空 -> 抓关键词 -> 连背景 -> 组织答案"展开。

## 质量检查

- 区分历史事实、材料信息和历史解释。
- 适合时使用表格或时间轴。
- 避免没有证据的空泛评价。
