# 数学章节笔记规范

数学章节笔记属于理科结构，应与物理、化学、生物保持相近的学习骨架，但数学更强调"定义条件、符号语言、性质定理、变形证明、题型方法"。

## Core Structure

在 `核心知识点讲解` 中使用以下内部结构：

```markdown
### 一、知识对象与问题情境
### 二、核心概念与定义条件
### 三、符号语言与等价表示
### 四、关键性质、定理与公式
### 五、典型模型与解题方法
### 六、题型应用与迁移
```

## 图片风格约束

数学配图统一使用精确的课堂板书与几何图示风格：白色或浅网格背景，黑色/深蓝线条为主，少量橙色突出关键条件、辅助线、变量或结论；坐标轴、几何图形、数轴、集合关系、函数图像和推导流程必须标注清楚，字母、公式和符号使用 LaTeX 风格。避免卡通、立体炫光和装饰性图案，重点保证比例、方向、对应关系和条件标注准确。

## 必须突出

- 清楚解释定义、条件、符号、反例和等价转化。
- 公式、定理必须说明前提条件、结论、证明思路、典型用法和常见陷阱。
- `核心知识点讲解` 必须像独立讲义：先用学习主线或问题链串起知识，再用通俗语言讲概念、符号、性质、推导和应用场景。不要写成“知识点清单 + 公式表”。
- `重点梳理` 必须详细讲解每个重点为什么重要、什么时候触发、怎么用、与前后知识如何连接；不能只罗列公式或关键词。
- `易错点整理` 必须包含常见错误表现、错因分析、反例或警示、正确处理步骤。
- `考点考证点整理` 必须写成可做题的复习单元，包含出题形式、关键条件、解题路径、典型题型和扣分点。
- 例题讲解按"审题 -> 转化 -> 运算/证明 -> 检验"展开。
- 练习题要覆盖概念判断、运算、证明、应用和综合题。
- `重点梳理` 要包含定义、条件、公式/定理、常见转化和方法触发条件。
- `难点突破` 聚焦隐藏条件、等价转化、参数分类、证明逻辑和常见反例。
- `例题讲解` 尽量覆盖概念判断、计算/变形、证明和综合应用。

## 质量检查

- 不只给公式，必须解释公式成立条件。
- 需要说明常见错误变形为什么不成立。
- 尽量区分"概念理解"和"计算/证明方法"。
- 公式和符号使用 Markdown/LaTeX 表示。
- 最终笔记不得出现“原文、教材、课本、OCR、回看、source、习题X.X第X题”等整理痕迹；题目和例子要改写成独立可读的训练材料。
