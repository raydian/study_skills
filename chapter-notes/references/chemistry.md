# 化学章节笔记规范

化学章节笔记属于理科结构，应与数学、物理、生物保持相近的学习骨架，但化学更强调"物质类别、宏观现象、微观粒子、符号方程、实验与转化"。

## Core Structure

在 `核心知识点讲解` 中使用以下内部结构：

```markdown
### 一、知识对象与物质情境
### 二、核心概念与物质分类
### 三、关键规律、反应原理与方程式
### 四、典型转化模型与分析方法
### 五、实验现象、装置与证据
### 六、题型应用与迁移
```

## 图片风格约束

化学配图统一使用实验记录本与微观粒子示意结合的风格：白色或浅灰背景，黑灰线稿，蓝色表示溶液/离子环境，绿色表示生成物或分类关系，橙色表示反应条件、电子转移、沉淀/气体等关键变化；图中化学式、离子符号、反应箭头和条件使用 LaTeX 风格标注。优先呈现实验装置、物质分类树、宏观现象-微观粒子-符号方程链条、离子反应过程、氧化还原电子转移图；避免写实照片质感、花哨渐变和与实验无关的装饰。

## 必须突出

- 讲物质时要说明名称、化学式、类别、性质、反应条件和典型现象。
- 讲反应时要写清反应物/生成物、条件；必要时补充离子方程式、氧化还原分析和实验现象。
- 建立"现象 -> 微观解释 -> 化学方程式 -> 应用/检验"的链条。
- 练习题覆盖物质推断、方程式书写、离子共存、实验设计、计算和推理。
- `重点梳理` 要包含物质类别、性质、方程式、反应条件、实验现象和检验方法。
- `难点突破` 聚焦微粒解释、方程式书写、离子拆分、氧化还原电子转移和实验推理。
- `例题讲解` 按"题眼/现象 -> 物质判断 -> 原理/方程式 -> 条件检查 -> 结论"展开。

## 公式与方程式规则

公式和化学方程式使用 Markdown/LaTeX 表示。

- 正文、表格、列表中的行内化学式、离子符号、价态符号和短反应式必须用单个 `$...$` 包裹，例如 `$H_{2}O$`、`$SO_{4}^{2-}$`、`$Fe(OH)_{3}$`、`$H^{+} + OH^{-} = H_{2}O$`。
- 不要在正文中裸写 `H_{2}O`、`Fe^{3+}`、`SO_{4}^{2-}`、`Na_{2}SO_{4} + BaCl_{2}` 等需要 LaTeX 渲染的内容。
- 单独成行展示的重要方程式使用 `$$...$$`，例如：

```markdown
$$
Na_{2}SO_{4} + BaCl_{2} = 2NaCl + BaSO_{4}\downarrow
$$
```

## 质量检查

- 检查方程式配平、电荷守恒和反应条件。
- 区分实验现象、原因解释、方程式和结论。
