## 核心组织结构

生物章节笔记使用理科学习骨架，并突出结构功能、生命过程、调控机制、实验变量和图表证据。`核心知识点讲解` 必须按以下顺序组织：

```markdown
### 一、知识对象与生命情境
### 二、核心概念与结构功能
### 三、关键过程、规律与调控机制
### 四、典型模型与分析方法
### 五、图表、实验与证据链
### 六、题型应用与迁移
```

每个概念尽量回答五个问题：对象在哪里、由什么构成、结构怎样、如何变化或发挥作用、对细胞或个体有何意义。不要把笔记写成定义和结论的清单。

## 图像驱动讲解

生物笔记默认采用“先看图获得事实，再由事实解释结构、过程和功能”的写法：

1. 在相关图注前后的正文点明图片身份、观察对象和阅读任务。
2. 先写图中能直接看到、读到或测得的事实。
3. 再写依据事实作出的结构判断、过程推理或功能解释。
4. 最后落到教材结论、题型方法或结论边界。

图片不能只是段落装饰。结构图用于讲清位置和组成，过程图用于讲清步骤和方向，实验图用于讲清变量和证据，曲线图用于讲清坐标、趋势和因果边界，照片用于识别真实对象及可观察特征。

难点若无法仅靠文字稳定理解，应增加一张局部“补充知识图”，例如结构层次展开图、动态过程链、因果链、对比矩阵、实验变量图或题型判断路径。已由简单表格充分表达的短知识点不强行配图。

## 教材视觉单元盘点

写作前必须先盘点源文中的全部视觉引用，再判断学习价值，不能边写边猜：

| 盘点字段 | 要求 |
|---|---|
| 源文件位置 | 记录图片引用附近的行号或小节 |
| 图片文件 | 记录源Markdown中的相对路径或文件名 |
| 图号与图题 | 原文有则原样记录；无图号时记录题目情境或对象名称 |
| 视觉类型 | 照片、显微图、结构模式图、过程图、曲线、表格、实验结果、科学史图片等 |
| 学习价值 | 核心知识、实验步骤、材料证据、练习依赖或无学习价值 |
| 输出位置 | 映射到具体笔记和正文标题附近 |
| 处理方式 | 教材源图重绘、按语义合并的教材源图组、忽略装饰图 |

盘点时必须实际查看图片。不得只根据文件名、OCR附近文字或记忆推断图片内容。栏目图标、页眉页脚、出版社标识、纯装饰底图不生成学习图注。多文件共同组成一个有统一图号或统一问题的多面板图时可合并，但注释要逐一写出每个面板；有独立学习含义的图片不得为了减少数量而合并。

源图盘点是最高优先级：教材有多少个有学习价值的视觉单元，就建立多少个可追溯映射，不受“一节2—5张图”的默认数量限制。

## 两类图片注释

生物笔记中的每条图片描述必须明确属于下列一种，不能混写。

### 1. 教材源图重绘

统一开头：

```markdown
<!-- 图片描述：教材图X-X源图重绘——“原图题名”。…… -->
```

没有图号时使用：

```markdown
<!-- 图片描述：教材“问题探讨”源图重绘——“对象名称”。…… -->
```

规则：

- 忠实保留原图主体、面板、标签、箭头、颜色含义、数据、坐标和图题。
- 只标原图实际可见或原文明确要求标出的结构；推断内容放在正文或独立补充图中。
- 不把照片擅自改造成流程图，不把肖像改造成时间轴，不把结构模型改造成实验路线。
- 不添加原图没有的细胞器、分子位置、过程箭头、实验数据或结论标签。
- 可以改善清晰度、排版、中文标注和颜色辨识，但不能改变科学含义。
- 如需在源图旁增加判读提示，必须与“源图主体区”分区，明确哪些是观察事实、哪些是教学解释。

### 2. 补充知识图

统一开头：

```markdown
<!-- 图片描述：补充知识图（非教材原图）——“图名”。…… -->
```

规则：

- 用于补充教材文字中的过程、机制、因果、比较、实验设计、证据链或解题路径。
- 必须说明节点、顺序、关系词、箭头方向、变量、颜色图例、关键结论和适用边界。
- 不得写“对应教材图X-X”，不得让读者误以为教材本来就有该图。
- 可引用教材事实，但要把直接事实、合理推理和拓展解释分层呈现。

同一条注释禁止同时承担“忠实重绘教材原图”和“补充完整机制”的任务。如教材只有病毒结构图，源图注释只重绘病毒结构；病毒增殖过程另写补充知识图。

## 图片注释最低信息

每条图片描述应尽量包含下列信息；不适用的项可省略，但不能写空泛占位：

1. 身份：教材图号/图题，或“补充知识图（非教材原图）”。
2. 主体：细胞、组织、器官、分子、实验装置、变量或生物对象。
3. 版式：左右对比、四格流程、纵向层次、显微视野、坐标曲线等。
4. 结构与标签：需要出现的中文名称及引线落点。
5. 关系与过程：箭头方向、步骤编号、反应物与产物、组成或调控关系。
6. 数据与图例：单位、比例尺、放大倍数、坐标、颜色含义和对照组。
7. 直接事实：从图中能够观察或读取的内容。
8. 推理结论：图支持什么结论，结论强度和适用范围是什么。
9. 插入价值：该图帮助解决哪一处概念障碍、实验判断或题型。
10. 风格：遵循本规范的教材式生物科学视觉语言。

禁止使用“以源图实际标签为准”“画若干结构”“展示相关过程”等把核对责任推给后续生图环节的含糊表述。标签、面板和步骤必须在当前注释中写清。

图片注释必须使用单行完整HTML注释，独立成段，前后保留空行：

```markdown
<!-- 图片描述：…… -->
```

不得使用错误结尾、跨段未闭合注释，或把下一段正文包进注释。

## 不同图片类型的写法

### 结构模式图

- 写清整体方向、层次、每个标注名称和引线落点。
- 区分真实存在的边界、膜、腔、链和颗粒，不用装饰线替代结构。
- 说明结构如何支持功能，但教学解释与源图标签分区。

### 显微照片和生物照片

- 保留显微视野、染色、真实形态、排列、比例尺或放大倍数。
- 只标可辨认结构；把位置推断或功能推断明确写成“推测”。
- 不把照片改成包含不可见细胞内部结构的模式图。

### 过程和机制图

- 给出起点、终点、步骤编号、物质或信息流向以及关键条件。
- 动态机制使用连续箭头，并在箭头上写关系词或变化内容。
- 存在反馈、促进、抑制或双向转化时使用不同线型并配图例。

### 实验图

- 写清材料、试剂/装置、实验组与对照组、自变量、因变量、控制变量。
- 将操作步骤、观察现象和结论分开；颜色反应写准确颜色、沉淀和必要条件。
- 图像证据只能支持相应强度的结论；“未检出”不等于“绝对不存在”。

### 曲线、柱状图和表格

- 写清横纵轴、单位、图例、数据点或统计口径。
- 讲解按“读轴与对象→描述趋势/差异→联系机制→限定结论”展开。
- 鲜重/干重、相对量/绝对量、浓度/含量不得混用。
- 重绘时不能擅自补造数据；估读值应说明是近似。

### 科学史图片

- 人物肖像、历史器具和实验场景应忠实重绘，不改造成包含额外史实的时间轴。
- 科学发现时间轴或证据链另作补充知识图，写清“问题—方法—证据—修正—结论”。

### 教材练习依赖图

- 题目依赖的概念图、结构式、曲线或生物识图必须单独映射。
- 忠实保留待填“？”、未知标签和题目给定信息，不能在源图重绘中提前填出答案。
- 详细答案可以在正文解释或另设补充判读图，不能破坏原题训练功能。

## 知识讲解与图片的绑定

每个真实小节开头配置一张“本节整体知识信息结构图”，且必须标为补充知识图。正文围绕教材图像组织时，推荐使用以下微结构：

```markdown
#### 教材图X-X：图题

先说明看图任务和图中可直接读取的事实。

<!-- 图片描述：教材图X-X源图重绘——…… -->

再解释结构、过程、功能、证据与题型迁移；需要完整机制时另加补充图。
```

图片注释要靠近其支持的段落。不得把全部源图注释集中在文末，也不得先写长篇结论后才出现对应图片。对复杂图，正文至少覆盖“怎么看、看到了什么、为什么、能得出什么、不能得出什么”。

## 实验、证据与材料题

涉及实验时必须明确：

- 研究目的和假设；
- 实验材料及选择理由；
- 自变量、因变量、控制变量；
- 实验组、对照组和重复；
- 操作条件与安全边界；
- 直接观察结果；
- 从结果到结论的推理；
- 误差来源和结论适用范围。

材料题按“提取事实→定位结构或过程→连接机制→形成结论→检查是否越界”作答。区分教材事实、由图可见事实、由材料支持的推理和超出材料的拓展知识。

## 练习和答案

- 收录教材概念检测、思考讨论、探究实践、拓展应用和章末复习中有学习价值的题目。
- 依赖图片的题必须写清图中已知信息，并保留对应教材源图注释。
- 答案不能只给选项；需写结构依据、过程链、实验逻辑或评分关键词。
- 图像题答案按“识图对象→直接证据→知识判断→完整表述”组织。
- 实验题答案按“对象—试剂/变量—操作—现象—结论—误差”组织。
- 动态过程、遗传、调节和结构功能题使用明确因果链，避免只复述结论。

## 生物学表达与视觉风格

生物配图统一使用高中教材式科学示意图风格：白色或浅绿灰背景，黑灰轮廓线；绿色表示生命结构或生理过程，蓝色表示调控、物质运输、实验条件或环境因素，橙色表示关键变量、能量变化、阳性结果或结论边界。结构图使用清晰中文标注，过程图使用方向箭头和步骤编号，图例不得只靠颜色表达。

避免卡通拟人、写实血腥、过度装饰、无意义3D透视和与实际尺度冲突的拼贴。分子结构、化学式、离子、电荷、肽键、碱基和方向必须科学准确。

## 强制校验

生成完成后，除通用校验外还必须检查：

1. 每条生物图片注释均以“教材……”或“补充知识图（非教材原图）”开头。
2. 所有教材图号、图题和有学习价值的无编号视觉单元均有映射；装饰图已排除。
3. 教材源图重绘未加入原图不可见结构或额外机制；补充图未冒充教材原图。
4. 多面板教材图的每个面板均在注释中列明。
5. 图片注释完整闭合、独立成段，前后为空行。
6. 正文明确区分直接观察、数据读取、推理结论和拓展说明。
7. 每个复杂结构、动态过程和实验难点都有足够的图像支持。
8. 教材练习依赖图保留未知信息，答案与题图一致。
9. 运行：

```bash
python3 skills/chapter-notes/scripts/validate_chapter_notes.py \
  "high_school/生物/章节笔记/<章节名>" \
  --stage comments --subject 生物 --source "markdown/生物/<教材>/拆分/章节/<源章节>.md"
```

图片生成并插入后再运行 `--stage images`。
