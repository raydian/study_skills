# 生物章节笔记规范

生物章节笔记属于理科结构，应与数学、物理、化学保持相近的学习骨架，但生物更强调"结构功能、生命过程、调控机制、实验变量、图表证据"。

## Core Structure

在 `核心知识点讲解` 中使用以下内部结构：

```markdown
### 一、知识对象与生命情境
### 二、核心概念与结构功能
### 三、关键过程、规律与调控机制
### 四、典型模型与分析方法
### 五、图表、实验与证据链
### 六、题型应用与迁移
```

## 图片风格约束

生物配图统一使用高中教材式科学示意图风格：白色或浅绿灰背景，黑灰轮廓线，绿色表示生命结构或生理过程，蓝色表示调控、物质运输或环境因素，橙色表示关键变量、能量变化或结论；结构图要有清晰中文标注，过程图要有方向箭头和步骤编号。优先使用细胞/器官结构功能图、生命过程链条图、遗传分析图、实验变量与对照图、曲线和表格证据图，避免卡通拟人、写实血腥和过度装饰。

## 必须突出

- 讲生物学概念时，要从结构、功能、位置、过程和意义解释。
- 光合作用、呼吸作用、有丝分裂、遗传、调节等过程要用步骤链条展开。
- 强调图示、表格、实验变量、对照组和结论推理。
- 练习题覆盖概念判断、图示标注、信息提取、实验分析、遗传/过程推理。
- `重点梳理` 要包含概念边界、结构与功能关系、过程链条、调控关系和实验变量。
- `难点突破` 聚焦易混概念、因果链条、图像解读、遗传推理和实验对照。
- `例题讲解` 按"提取信息 -> 判断结构/过程 -> 找证据 -> 推理结论 -> 检查表述"展开。

## 质量检查

- 区分教材事实和推理结论。
- 对动态机制使用过程链条。
- 涉及实验时必须包含变量、对照和结论逻辑。
