# 英语章节笔记规范

英语章节笔记属于语言学习型结构，应围绕"语言知识、语篇理解、语法功能、表达迁移、考试应用"展开，不要套用理科公式化结构，也不要只做单词表。

## Core Structure

在 `核心知识点讲解` 中使用以下内部结构：

```markdown
### 一、语篇主题与学习任务
### 二、核心词汇、短语与搭配
### 三、重点句型与长难句
### 四、核心语法的形式、意义与使用
### 五、语篇结构、逻辑衔接与文化语境
### 六、听说读写迁移与考试应用
```

## 图片风格约束

英语配图统一使用干净的语言学习工作纸风格：白色或浅蓝灰背景，深蓝/墨绿主色，少量橙色强调关键词；优先呈现词汇网络、句子成分框图、语法形式-意义-使用三栏图、语篇结构图、段落逻辑衔接图和写作模板图。图中文字以英文为主，必要时加入简短中文解释；避免无关人物照片、旅游风景和装饰性插画。

## 必须突出

- `本节学习目标`: 说明词汇、短语、语法、语篇阅读、听说写任务和考试能力目标。
- `核心知识点讲解`: 包含核心词汇、构词、短语、句型、语法的形式-意义-使用、语篇结构和语用功能。
- `重点梳理`: 提炼高频词、固定搭配、重点句型、语法规则、话题表达和写作素材。
- `难点突破`: 讲清易混词、介词/搭配、长难句、时态语态、非谓语、从句或语篇逻辑。
- `例题讲解`: 使用词汇、语法填空、阅读理解、句子翻译、仿写、读后续写或应用文写作例题。
- `易错点整理`: 覆盖拼写、词性、汉英迁移、搭配错误、时态不一致、冠词/介词错误和句子残缺。
- `考点考证点整理`: 总结完形填空、阅读推断、语法填空、写作句式升级、读后续写和应用文写作考法。
- `练习题`: 包含词汇、短语、语法、阅读、翻译、仿写和写作训练。
- `练习题答案`: 用中文解释，保留英文例句，必要时给出更优表达。

## Recommended Inner Structure

```markdown
### 一、核心词汇
### 二、核心短语与固定搭配
### 三、重点句型
### 四、核心语法
### 五、语篇结构与段落理解
### 六、写作表达迁移
```

以上 `Core Structure` 是主结构；`Recommended Inner Structure` 可用于词汇、语法占比较高的小节。

## 阅读与语法

阅读语篇需要包含逐段或逐句讲解：

```markdown
### 逐段精读

- 原文要点：
- 中文理解：
- 语言点：
- 长难句：
- 考点提示：
```

语法小节按"形式 -> 意义 -> 使用 -> 常见错误 -> 练习"展开，不能只下定义。
