# 物理章节笔记规范

物理章节笔记属于理科结构，应与数学、化学、生物保持相近的学习骨架，但物理更强调"情境建模、过程分析、公式条件、图像实验、结果检验"。

## Core Structure

在 `核心知识点讲解` 中使用以下内部结构：

```markdown
### 一、知识对象与物理情境
### 二、核心概念与物理意义
### 三、关键规律、公式与适用条件
### 四、典型模型与过程分析
### 五、图像、实验与数据理解
### 六、题型应用与迁移
```

## 图片风格约束

物理配图统一使用清晰的工程示意与物理建模风格：白色或浅网格背景，黑灰实体轮廓，蓝色表示速度、位移、场线或过程，橙色表示力、加速度、关键条件或结论；必须标出研究对象、坐标轴、方向箭头、状态点、物理量符号、单位和必要公式。优先使用受力图、运动过程图、图像斜率/面积示意、实验装置简图和能量/电路/场模型图，避免写实复杂背景和装饰性插画。

## 必须突出

- 先讲物理意义，再给公式。
- 每个公式都要说明符号、单位、矢量/标量属性、适用条件和常见变式。
- 例题要包含研究对象选择、过程选择、受力/运动分析、列方程、计算和结果检验。
- 需要图像推理时，保留示意图或 `[图片：...]` 占位。
- `重点梳理` 要包含概念、公式、适用条件、单位、模型识别提示和图像/实验含义。
- `难点突破` 聚焦研究对象选择、过程选择、受力/状态分析、矢量方向和公式条件。
- `例题讲解` 按"读题 -> 选对象 -> 判过程 -> 建模型 -> 列方程 -> 检查单位/方向"展开。

## 质量检查

- 列方程前先说明研究对象、过程、状态和条件。
- 涉及图像时解释斜率、面积、截距及其物理意义。
- 答案要检查单位、方向和数量级是否合理。
