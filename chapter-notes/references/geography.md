# 地理章节笔记规范

地理章节笔记属于综合分析型结构，兼具自然科学和人文社会分析特点，应围绕"区域定位、自然/人文要素、过程机制、图表判读、综合分析"展开，不完全套用理科公式结构。

## Core Structure

在 `核心知识点讲解` 中使用以下内部结构：

```markdown
### 一、区域定位与地理情境
### 二、核心概念与地理要素
### 三、过程机制与成因链条
### 四、空间分布、图表判读与证据
### 五、人地关系、影响与对策
### 六、综合题型与迁移应用
```

## 图片风格约束

地理配图统一使用地图信息图与过程机制图风格：白色或浅地形色背景，蓝色表示水文/大气，绿色表示植被/农业/生态，橙色表示热量、城市、产业或风险点，黑灰表示边界、坐标和文字；必须包含必要的图例、方向、层次、箭头、区域标签或数据标注。优先使用区域定位图、空间分布图、自然过程链条图、区位因素雷达/框图、剖面图、统计图表判读示意，避免纯风景图和无地图信息的装饰图。

## 必须突出

- 讲地理概念时按位置、分布、成因、过程、影响和对策展开。
- 自然地理强调机制链，例如"太阳辐射 -> 大气环流 -> 气候 -> 植被/水文"。
- 人文地理强调区位因素、工业/农业/城市逻辑、区域发展和可持续性。
- 例题包含读图定位、图表判读、因素分析、区域比较和措施评价。
- 练习题包含定位、过程解释、成因分析、图表判读和区域综合题。
- `重点梳理` 要包含位置、分布、成因、过程、影响、措施和地图/图表判读提示。
- `难点突破` 聚焦机制链条、因素完整性、区域比较和材料信息提取。
- `例题讲解` 按"定位 -> 读图表 -> 找因素 -> 构建因果链 -> 分点作答"展开。

## 质量检查

- 适合时使用"位置 -> 分布 -> 成因 -> 影响 -> 对策"。
- 区分自然因素和人文因素。
- 必要时保留地图/图表，或使用 `[图片：...]` 占位。
