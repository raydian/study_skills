# 地理章节笔记规范

地理章节笔记属于综合分析型结构，兼具自然科学和人文社会分析特点，应围绕"区域定位、自然/人文要素、过程机制、图表判读、综合分析"展开，不完全套用理科公式结构。

## Core Structure

在 `核心知识点讲解` 中使用以下内部结构：

```markdown
### 一、区域定位与地理情境
### 二、核心概念与地理要素
### 三、过程机制与成因链条
### 四、空间分布、图表判读与证据
### 五、人地关系、影响与对策
### 六、综合题型与迁移应用
```

## 图片风格约束

地理配图统一使用地图信息图与过程机制图风格：白色或浅地形色背景，蓝色表示水文/大气，绿色表示植被/农业/生态，橙色表示热量、城市、产业或风险点，黑灰表示边界、坐标和文字；必须包含必要的图例、方向、层次、箭头、区域标签或数据标注。优先使用区域定位图、空间分布图、自然过程链条图、区位因素雷达/框图、剖面图、统计图表判读示意，避免纯风景图和无地图信息的装饰图。

## 子章节拆分规则

地理教材的每个真实教学小节必须独立成文档，不把“第一节、第二节”等小节压缩成一篇章节摘要：

- 按教材原有的 `第一节`、`第二节`、`第三节`、`第四节` 等边界拆分，文件名保留小节序号和原题名。
- “问题研究”或专题探究若含独立材料、设问、资料分析和结论，单独生成章末/专题笔记；短小的“活动”“思考”“案例”放回所属小节，并在例题、练习或方法中保留其地理推理价值。
- 每个小节文档都必须完整包含区域定位、要素与概念、机制链、图表证据、人地关系、综合题型等适用结构；不能因为拆分而只留下结论或知识点清单。
- 章首 MOC 必须链接全部小节和独立专题，并说明“自然过程—空间分布—人类影响—综合应用”的章节主线。

## 源图逐一注释规则

地理知识的理解高度依赖地图、剖面图、分布图、统计图和过程示意图。生成章节笔记时，先按小节建立源图清单，再逐图处理：

- 原文提到的每一个有知识价值的图、地图、图表、实验/观测照片或多面板视觉单元，都要在对应段落附近新增一个具体的 `<!-- 图片描述：... -->` 注释；注释中写明“对应源文图X/图题”，不能只写“见图”。
- 多面板图只有在各面板表达同一结论时才合并为一个注释；如果面板分别表达位置、分布、过程或变化趋势，则分别说明，避免漏掉独立知识。
- 每个小节开头保留一张“本节整体知识信息结构图”注释；其余图片数量由源图清单和讲解难点决定，不受固定 2–5 张上限限制。源图少时，再补充必要的机制链、读图步骤或综合题答题路径图。
- 注释必须说明地图范围/定位、图例、方向或坐标、地理要素、颜色含义、箭头过程、数据趋势、因果链及学生应得出的结论。优先把“位置→分布→成因→过程→影响→对策”画成可判读的结构。
- 图片生成后紧邻注释上方插入相对路径图片，文件名不得出现空格，使用中划线或下划线，例如 `images/第二节-太阳对地球的影响-图1-14.webp`。图片可被相关笔记共享，但所有引用必须可解析。
- 如果源图暂时无法重绘，保留完整注释和“需回看原图确认”的具体说明，不得删掉源图对应的知识讲解。

## 必须突出

- 讲地理概念时按位置、分布、成因、过程、影响和对策展开。
- 自然地理强调机制链，例如"太阳辐射 -> 大气环流 -> 气候 -> 植被/水文"。
- 人文地理强调区位因素、工业/农业/城市逻辑、区域发展和可持续性。
- 例题包含读图定位、图表判读、因素分析、区域比较和措施评价。
- 练习题包含定位、过程解释、成因分析、图表判读和区域综合题。
- `重点梳理` 要包含位置、分布、成因、过程、影响、措施和地图/图表判读提示。
- `难点突破` 聚焦机制链条、因素完整性、区域比较和材料信息提取。
- `例题讲解` 按"定位 -> 读图表 -> 找因素 -> 构建因果链 -> 分点作答"展开。

## 质量检查

- 适合时使用"位置 -> 分布 -> 成因 -> 影响 -> 对策"。
- 区分自然因素和人文因素。
- 必要时保留地图/图表；若暂时没有可用图片文件，必须使用完整的 `图片描述` 注释说明待生成内容，不得只留下 `[图片：...]` 占位。
