# 英语题库整理规范

## Output

```text
high_school/英语/题库整理/<题库名称>.md
```

## Required Structure

```markdown
# 题库名称

## 题库说明
## 适用范围
## 知识点标签
## 题型分类
## 难度分层
## 基础题
## 巩固题
## 提升题
## 综合题
## 答案与解析
## 错题回收建议
```

## Single Question Format

```markdown
### 题目 1

- 来源：
- 知识点：
- 难度：
- 题型：
- 训练目标：

题目正文

#### 答案
#### 解析
#### 关键点
#### 易错点
```

## Question Types

- 词汇、语法填空、阅读理解、七选五、完形填空。
- 翻译、应用文写作、读后续写、语篇分析。

## Requirements

- Preserve English passages and options exactly when available.
- Explanations should identify evidence, grammar structure, collocation, or discourse logic.
- Writing questions should include task type, key expressions, and scoring focus.
