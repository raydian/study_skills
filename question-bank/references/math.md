# 数学题库整理规范

## Output

```text
high_school/数学/题库整理/<题库名称>.md
```

## Required Structure

```markdown
# 题库名称

## 题库说明
## 适用范围
## 知识点标签
## 题型分类
## 难度分层
## 基础题
## 巩固题
## 提升题
## 综合题
## 答案与解析
## 错题回收建议
```

## Single Question Format

```markdown
### 题目 1

- 来源：
- 知识点：
- 难度：
- 题型：
- 训练目标：

题目正文

#### 答案
#### 解析
#### 关键点
#### 易错点
```

## Question Types

- 选择题、填空题、解答题、证明题、应用题、压轴题。
- 函数、不等式、三角、数列、立体几何、解析几何、概率统计、导数。

## Requirements

- Keep formulas in Markdown/LaTeX.
- Explanations must show the thinking path, not only final calculation.
- Sort similar questions from direct use to transformation to comprehensive application.
