# 历史题库整理规范

## Output

```text
high_school/历史/题库整理/<题库名称>.md
```

## Required Structure

```markdown
# 题库名称

## 题库说明
## 适用范围
## 知识点标签
## 题型分类
## 难度分层
## 基础题
## 巩固题
## 提升题
## 综合题
## 答案与解析
## 错题回收建议
```

## Single Question Format

```markdown
### 题目 1

- 来源：
- 知识点：
- 难度：
- 题型：
- 训练目标：

题目正文

#### 答案
#### 解析
#### 关键点
#### 易错点
```

## Question Types

- 选择题、材料题、比较题、原因影响题、小论文题。
- 政治制度、经济发展、思想文化、中外关系、阶段特征。

## Requirements

- Preserve source materials and citations when available.
- Explanations should identify time, space, source standpoint, keywords, and historical interpretation.
- Sort from factual recognition to material interpretation to argument construction.
