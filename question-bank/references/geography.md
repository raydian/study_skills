# 地理题库整理规范

## Output

```text
high_school/地理/题库整理/<题库名称>.md
```

## Required Structure

```markdown
# 题库名称

## 题库说明
## 适用范围
## 知识点标签
## 题型分类
## 难度分层
## 基础题
## 巩固题
## 提升题
## 综合题
## 答案与解析
## 错题回收建议
```

## Single Question Format

```markdown
### 题目 1

- 来源：
- 知识点：
- 难度：
- 题型：
- 训练目标：

题目正文

#### 答案
#### 解析
#### 关键点
#### 易错点
```

## Question Types

- 地图题、图表题、等值线题、区域综合题、区位分析题、措施评价题。
- 自然地理、人文地理、区域地理、资源环境与可持续发展。

## Requirements

- Preserve maps, charts, legends, and data or use `[图片：...]` placeholders.
- Explanations should identify location, distribution, causes, impacts, and measures.
- Sort by map reading, concept application, factor analysis, and comprehensive synthesis.
