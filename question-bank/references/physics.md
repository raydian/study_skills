# 物理题库整理规范

## Output

```text
high_school/物理/题库整理/<题库名称>.md
```

## Required Structure

```markdown
# 题库名称

## 题库说明
## 适用范围
## 知识点标签
## 题型分类
## 难度分层
## 基础题
## 巩固题
## 提升题
## 综合题
## 答案与解析
## 错题回收建议
```

## Single Question Format

```markdown
### 题目 1

- 来源：
- 知识点：
- 难度：
- 题型：
- 训练目标：

题目正文

#### 答案
#### 解析
#### 关键点
#### 易错点
```

## Question Types

- 概念判断、图像题、实验题、计算题、综合应用题。
- 运动学、受力分析、牛顿定律、能量、动量、电磁、实验。

## Requirements

- Preserve diagrams or add `[图片：...]` placeholders when necessary.
- Explanations should include object, process, model, equation, unit, and direction checks.
- Sort questions by model complexity and required reasoning steps.
