# 生物题库整理规范

## Output

```text
high_school/生物/题库整理/<题库名称>.md
```

## Required Structure

```markdown
# 题库名称

## 题库说明
## 适用范围
## 知识点标签
## 题型分类
## 难度分层
## 基础题
## 巩固题
## 提升题
## 综合题
## 答案与解析
## 错题回收建议
```

## Single Question Format

```markdown
### 题目 1

- 来源：
- 知识点：
- 难度：
- 题型：
- 训练目标：

题目正文

#### 答案
#### 解析
#### 关键点
#### 易错点
```

## Question Types

- 概念判断、图表题、实验题、遗传题、过程推理题、综合题。
- 细胞、代谢、遗传、稳态、生态、实验探究。

## Requirements

- Preserve diagrams, tables, data, and experiment conditions.
- Explanations should distinguish facts, evidence, reasoning, and conclusion.
- Sort by concept recognition, data extraction, mechanism reasoning, and comprehensive application.
