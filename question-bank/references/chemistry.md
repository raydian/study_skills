# 化学题库整理规范

## Output

```text
high_school/化学/题库整理/<题库名称>.md
```

## Required Structure

```markdown
# 题库名称

## 题库说明
## 适用范围
## 知识点标签
## 题型分类
## 难度分层
## 基础题
## 巩固题
## 提升题
## 综合题
## 答案与解析
## 错题回收建议
```

## Single Question Format

```markdown
### 题目 1

- 来源：
- 知识点：
- 难度：
- 题型：
- 训练目标：

题目正文

#### 答案
#### 解析
#### 关键点
#### 易错点
```

## Question Types

- 选择题、离子反应题、氧化还原题、推断题、实验题、计算题、流程题。
- 物质分类、元素化合物、物质结构、化学计量、实验探究。

## Requirements

- Use Markdown/LaTeX for chemical formulas and equations.
- Explanations should include phenomenon, particle logic, equation logic, and checks.
- Keep experiment diagrams, flowcharts, or placeholders when needed.
