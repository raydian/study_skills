# 语文知识点专题规范

## Output

```text
high_school/语文/知识点专题/<专题名称>.md
```

## Required Structure

```markdown
# 专题名称

## 专题定位
## 涉及材料
## 核心知识点
## 知识网络
## 方法与答题思路
## 典型题型
## 例题精讲
## 易错点
## 考法总结
## 专题练习
## 练习答案与解析
```

## Topic Types

- 文言实词、虚词、特殊句式、词类活用。
- 诗歌意象、情感判断、表现手法、炼字炼句。
- 小说人物形象、环境描写、叙述视角、主题探究。
- 散文线索、语言赏析、情感脉络。
- 论述类文本论证结构、论证方法、观点态度。
- 作文审题立意、素材积累、结构模板、语言表达。

## Requirements

- Organize by reusable knowledge point or ability, not by lesson title.
- Include answer patterns and scoring points for exam-facing topics.
- Use examples from multiple texts when helpful.
- Do not copy full textbook passages.
