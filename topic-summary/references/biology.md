# 生物知识点专题规范

## Output

```text
high_school/生物/知识点专题/<专题名称>.md
```

## Required Structure

```markdown
# 专题名称

## 专题定位
## 涉及知识
## 核心概念
## 知识网络
## 关键过程与规律
## 典型模型
## 解题方法
## 例题精讲
## 易错点
## 考法总结
## 专题练习
## 练习答案与解析
```

## Topic Types

- 细胞结构与功能、物质跨膜运输、酶与 ATP。
- 光合作用、呼吸作用、有丝分裂、减数分裂。
- 遗传规律、基因表达、变异与进化。
- 神经调节、体液调节、免疫调节、生态系统。
- 实验变量、对照原则、图表分析。

## Requirements

- Explain terms through structure, location, function, process, and significance.
- Use process chains for dynamic mechanisms.
- Emphasize experimental variables, controls, and conclusion logic.
- Exercises should include concept judgment, diagram reading, information extraction, experiment analysis, and reasoning.
