# 物理知识点专题规范

## Output

```text
high_school/物理/知识点专题/<专题名称>.md
```

## Required Structure

```markdown
# 专题名称

## 专题定位
## 涉及知识
## 核心概念
## 知识网络
## 关键规律与公式
## 典型模型
## 解题方法
## 例题精讲
## 易错点
## 考法总结
## 专题练习
## 练习答案与解析
```

## Topic Types

- 运动图像、追及相遇、匀变速模型。
- 受力分析、摩擦力、弹力、牛顿定律应用。
- 功能关系、机械能守恒、动量模型。
- 电场、磁场、电路、实验数据处理。

## Requirements

- Explain physical meaning, applicable conditions, units, and vector/scalar properties.
- Include model identification cues and process analysis.
- Use diagrams or `[图片：...]` placeholders when visual reasoning matters.
- Exercises should cover concept judgment, calculation, graph reading, experiment, and comprehensive application.
