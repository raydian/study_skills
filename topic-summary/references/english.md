# 英语知识点专题规范

## Output

```text
high_school/英语/知识点专题/<专题名称>.md
```

## Required Structure

```markdown
# 专题名称

## 专题定位
## 涉及语言知识
## 核心规则
## 知识网络
## 典型用法
## 例句精讲
## 解题方法
## 易错点
## 考法总结
## 专题练习
## 练习答案与解析
```

## Topic Types

- 时态语态、非谓语动词、定语从句、名词性从句、状语从句。
- 词性转换、固定搭配、熟词生义、近义词辨析。
- 阅读理解定位、推断题、主旨题、七选五逻辑。
- 完形填空、语法填空、应用文写作、读后续写表达。

## Requirements

- Use "form -> meaning -> use -> common mistakes -> practice" for grammar.
- Keep English examples natural and level-appropriate.
- Explain Chinese-English transfer errors.
- Do not create `Unit X` topic files unless the topic is a cross-unit knowledge point.
