# 化学知识点专题规范

## Output

```text
high_school/化学/知识点专题/<专题名称>.md
```

## Required Structure

```markdown
# 专题名称

## 专题定位
## 涉及知识
## 核心概念
## 知识网络
## 关键规律与方程式
## 典型模型
## 解题方法
## 例题精讲
## 易错点
## 考法总结
## 专题练习
## 练习答案与解析
```

## Topic Types

- 物质分类、离子反应、离子共存、氧化还原。
- 钠、氯、铁、铝等元素化合物。
- 化学计量、物质的量、溶液浓度。
- 化学实验、物质检验、气体制备、实验安全。
- 物质结构、元素周期律、化学键。

## Requirements

- Include substance names, formulas, categories, properties, conditions, and phenomena.
- Write equations accurately, including ionic equations when needed.
- Explain oxidation states and electron transfer for redox topics.
- Exercises should include identification, equation writing, experiment design, calculation, and inference.
