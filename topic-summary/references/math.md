# 数学知识点专题规范

## Output

```text
high_school/数学/知识点专题/<专题名称>.md
```

## Required Structure

```markdown
# 专题名称

## 专题定位
## 涉及知识
## 核心概念
## 知识网络
## 关键性质与公式
## 典型题型
## 解题方法
## 例题精讲
## 易错点
## 考法总结
## 专题练习
## 练习答案与解析
```

## Topic Types

- 集合与逻辑用语、函数性质、基本初等函数。
- 不等式、三角恒等变换、三角函数图像。
- 数列通项、数列求和、递推关系。
- 立体几何、解析几何、概率统计。
- 导数应用、参数分类讨论、压轴题方法。

## Requirements

- State definitions, conditions, symbols, equivalent forms, and counterexamples.
- Explain formula derivations or proof ideas when useful.
- Include problem-recognition cues and step-by-step solution methods.
- Exercises must progress from concept checks to comprehensive problems.
