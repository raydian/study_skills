# 地理知识点专题规范

## Output

```text
high_school/地理/知识点专题/<专题名称>.md
```

## Required Structure

```markdown
# 专题名称

## 专题定位
## 涉及知识
## 核心概念
## 知识网络
## 关键过程与规律
## 典型模型
## 解题方法
## 例题精讲
## 易错点
## 考法总结
## 专题练习
## 练习答案与解析
```

## Topic Types

- 地球运动、大气环流、气候类型、水循环。
- 地貌形成、河流地貌、自然灾害。
- 农业区位、工业区位、交通区位、城市空间。
- 人口迁移、区域发展、资源环境与可持续发展。
- 地图判读、等值线、图表分析、区域综合题。

## Requirements

- Explain by location, distribution, cause, process, effect, and response.
- Use mechanism chains for natural geography.
- Use factor analysis and sustainability framing for human geography.
- Exercises should include map reading, chart interpretation, cause analysis, regional comparison, and measure evaluation.
