# Silent Remotion Studio and voiceover handoff

**REQUIRED SUB-SKILLS:** Use `remotion-best-practices` for the Remotion project and Studio preview. After explicit Studio approval, use `video-voiceover` for TTS generation and measured-timing synchronization.

## Ownership boundary

`deep-book-video` owns:

- the source-backed page script and future voiceover text;
- AI-generated static backgrounds;
- large editorial page subtitles;
- the silent Remotion composition and estimated frame timeline;
- Remotion Studio visual confirmation;
- a `video-voiceover`-compatible handoff package.

It does not own audio synthesis or rendering. Before Studio approval it must not create audio, install/use `@remotion/media`, add `<Audio>`, create `public/audio`, invoke TTS, or call a voiceover API. At all stages it **MUST NOT render** a still, preview video, or final MP4.

After the user explicitly approves the silent Studio composition, `video-voiceover` owns audio synthesis and the replacement of estimated scene timings with measured audio timings. After that handoff, return to Studio for synchronization review. Rendering remains a separate, later user-authorized task.

## Project setup

Before creating project files or installing packages, follow [remotion-project-setup.md](remotion-project-setup.md). Resolve the enclosing `video_root`, find a compatible shared `node_modules` within it, and link the new project to that directory. Do not run a project-local install when the shared dependency tree is valid.

If no usable shared tree exists, establish the dependency set once at the designated shared location under `video_root`, then create the project's symbolic link. Do not use a scaffolding flow that silently installs another full project-local copy. Add `@remotion/fonts` and `@remotion/layout-utils` to the shared dependency set only after compatibility review. Record the selected target in `dependency-link.json`.

Do not install `@remotion/media` during the silent stage. Use this minimum layout:

```text
remotion/
├── package.json
├── node_modules -> <shared node_modules inside video_root>
├── dependency-link.json
├── voiceover-script.json
├── voiceover-handoff.json
├── src/
│   ├── index.ts
│   ├── Root.tsx
│   ├── BookVideo.tsx
│   ├── timeline.json
│   ├── components/
│   │   ├── StaticBookPage.tsx
│   │   └── SubtitlePanel.tsx
│   └── data/
│       ├── video-script.json
│       └── subtitles.ts
└── public/
    ├── images/p001.png
    └── fonts/source-han-sans-sc-bold.woff2
```

Put images and fonts under `public/` and resolve them with `staticFile()`. Initial project inspection must find no audio directory or audio component.

## Silent composition

Register one `DeepBookVideo` composition. Read dimensions and fps from `video-script.json`; read scene durations and total frames from `src/timeline.json`. The latter starts with estimated page durations and becomes the measured source of truth after `video-voiceover --sync-remotion`.

Initial `timeline.json`:

```json
{
  "fps": 30,
  "totalFrames": 300,
  "scenes": [
    {
      "id": "P001",
      "name": "P001｜开场：看不见的规则",
      "durationFrames": 300
    }
  ]
}
```

Use adjacent, explicit named `Series.Sequence` blocks with no overlap or offset. Studio page sequences must be explicit authored JSX, not elements generated by `.map()`:

```tsx
import {AbsoluteFill, Img, Series, staticFile} from 'remotion';
import script from './data/video-script.json';
import timeline from './timeline.json';

const pages = Object.fromEntries(
  script.pages.map((page) => [page.page_id, page]),
) as Record<string, (typeof script.pages)[number]>;

const StaticBookPage = ({page}: {page: (typeof script.pages)[number]}) => (
  <AbsoluteFill style={{backgroundColor: '#000'}}>
    <Img
      src={staticFile(page.remotion_timeline.image_src)}
      style={{width: '100%', height: '100%', objectFit: 'cover'}}
    />
    <div
      style={{
        position: 'absolute',
        left: '5%',
        right: '5%',
        bottom: '8%',
        padding: '0.35em 0.5em',
        color: page.subtitle.text_color,
        background: 'rgba(0,0,0,0.72)',
        fontFamily: page.subtitle.font_family,
        fontSize: page.subtitle.font_size_px,
        fontWeight: page.subtitle.font_weight,
        lineHeight: 1.22,
        whiteSpace: 'pre-line',
      }}
    >
      {page.subtitle.lines.join('\n')}
    </div>
  </AbsoluteFill>
);

export const BookVideo = () => (
  <Series>
    <Series.Sequence
      name="P001｜开场：看不见的规则"
      durationInFrames={timeline.scenes[0].durationFrames}
    >
      <StaticBookPage page={pages.P001} />
    </Series.Sequence>

    <Series.Sequence
      name="P002｜模型：规则如何形成"
      durationInFrames={timeline.scenes[1].durationFrames}
    >
      <StaticBookPage page={pages.P002} />
    </Series.Sequence>
  </Series>
);
```

The data lookup may use `.map()`; the timeline sequence elements may not. Generate one literal sequence block per canonical page, with the `name` prop set to the literal `studio_sequence_name`. Keep `page_id`, image filename, timeline scene ID/name, sequence name, voiceover scene, and QA references aligned.

Do not import `Audio`. Do not use `useCurrentFrame()`, `interpolate()`, CSS transitions, CSS animations, springs, transforms, fades, zoom, parallax, or overlapping sequences. One page's pixels remain unchanged for its full frame interval.

## Estimated frame math

Before audio exists, estimate frames from cumulative seconds:

```text
start_frame[i] = round(sum(duration_seconds[0:i]) × fps)
end_frame_exclusive[i] = round(sum(duration_seconds[0:i+1]) × fps)
duration_in_frames[i] = end_frame_exclusive[i] - start_frame[i]
```

Require the first start to be 0, every page to start at the previous exclusive end, every duration to be positive, and `timeline.totalFrames` to equal the final exclusive end. These are layout-review estimates only. Do not generate silent padding files or fake audio to enforce them.

## Subtitles and fonts

The large page subtitle is an editorial cognitive anchor, not the full voiceover transcript. Render its supplied line breaks throughout the page. Load the declared CJK font with `@remotion/fonts`, then use `@remotion/layout-utils` to detect overflow with the same font family, size, weight, spacing, width, and line count used in the component.

If the text does not fit, rewrite or split the page. Do not shrink below 64 px for a 1920×1080 master. `video-voiceover` synchronization must not overwrite the page anchor with the longer narration text.

## Studio Confirmation Gate

Start Studio only:

```bash
npx remotion studio --no-open
```

Open the printed URL and inspect the entire silent composition in Studio. Check:

- every page appears in the intended order;
- every timeline item visibly shows the intended `P###｜page name` and is independently selectable;
- clicking an item seeks to the correct page and its duration matches `timeline.json`;
- page image, crop, subtitle, safe zone, font, and contrast are correct;
- hard cuts and estimated hold times feel reasonable;
- no audio asset, audio component, motion, or rendering output exists;
- the Studio console has no missing-asset, font, or overflow error.

Do not call `npx remotion still` or `npx remotion render`. A successful Studio launch is not approval. Keep:

```json
{
  "studio_confirmation": "pending",
  "voiceover_status": "blocked_until_studio_confirmed"
}
```

Stop and request explicit user confirmation. This gate is mandatory.

## Voiceover handoff

After explicit approval, set the confirmation to `approved` and the handoff status to `ready`. Create JSON marks compatible with `video-voiceover`:

```json
[
  {
    "id": "vo-P001-01",
    "scene": "P001",
    "text": "我们通常把失败归因于能力不足，但作者追问的是：是否有一套看不见的规则，提前划定了行动边界？",
    "subtitle": "真正限制我们的，也许不是能力，而是看不见的规则。",
    "tone": "克制、清晰，在问句前短暂停顿。",
    "speechRate": -1,
    "pauseAfterMs": 240
  }
]
```

Use one or more marks per page. Keep `scene` equal to `page_id`; keep full spoken text in `text`; keep the short page anchor in `subtitle`. For long narration, split marks at semantic boundaries without inventing new page claims.

Invoke `video-voiceover` with:

- `video_dir`: the Remotion project directory;
- `script`: `voiceover-script.json`;
- the selected supported subject or explicit speaker;
- `--sync-remotion` so measured audio durations update `src/timeline.json` and `src/data/subtitles.ts`.

For literature/classics use 语文; for history/biography use 历史; for a clearly matching science subject use that subject. For philosophy, psychology, business, management, economics, or other unsupported profiles, require the user to select a supported subject profile or account-specific speaker. Never invent a speaker ID.

The handoff contract is:

```json
{
  "skill": "video-voiceover",
  "status": "ready",
  "script_file": "voiceover-script.json",
  "sync_remotion": true,
  "render_after_voiceover": false,
  "preview_after_voiceover": true
}
```

After synthesis and synchronization, reopen Remotion Studio and check real audio timing, page starts, subtitle anchoring, missing speech, blank tails, and ending alignment. Do not render. A future render requires a new explicit user request.
