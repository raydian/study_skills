# 物理试卷分析规范

## Output

```text
high_school/物理/试卷解析/<试卷名称>解析.md
```

## Required Structure

```markdown
# 试卷名称解析

## 试卷信息
## 试卷结构与题型分布
## 整体表现
## 知识点与能力点分布
## 分题型解析
## 逐题解析
## 错题分类
## 失分原因分析
## 高价值题目
## 后续复习计划
## 需要进入错题本的题目
```

## Question Types

- 选择题、实验题、计算题、图像题、综合应用题。
- 运动学、相互作用、牛顿定律、能量、动量、电磁、实验。

## Analysis Focus

- 每题分析研究对象、物理过程、模型、公式条件和单位方向。
- 图像题分析斜率、面积、截距、交点的物理意义。
- 实验题分析仪器读数、变量控制、误差来源和数据处理。
- 失分归因区分建模错误、受力错误、公式条件错误、计算/单位错误。

## Follow-Up Routing

- 典型错题进入 `错题本/`。
- 运动图像、受力分析等进入 `知识点专题/` 或 `方法总结/`。
- 同类计算题进入 `题库整理/`。
