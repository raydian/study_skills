# 英语试卷分析规范

## Output

```text
high_school/英语/试卷解析/<试卷名称>解析.md
```

## Required Structure

```markdown
# 试卷名称解析

## 试卷信息
## 试卷结构与题型分布
## 整体表现
## 知识点与能力点分布
## 分题型解析
## 逐题解析
## 错题分类
## 失分原因分析
## 高价值题目
## 后续复习计划
## 需要进入错题本的题目
```

## Question Types

- 听力、阅读理解、七选五、完形填空。
- 语法填空、短文改错或语言运用。
- 应用文写作、读后续写、概要写作。

## Analysis Focus

- 阅读看定位、推断、主旨、词义猜测和干扰项。
- 完形看上下文逻辑、词义辨析和语篇连贯。
- 语法填空看词性、谓语/非谓语、从句、时态语态。
- 写作看内容要点、结构、语言准确性、表达升级和衔接。

## Follow-Up Routing

- 高频语言错误进入 `错题本/`。
- 阅读定位、七选五等流程进入 `方法总结/`。
- 语法、搭配、写作表达进入 `知识点专题/`。
