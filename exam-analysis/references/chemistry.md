# 化学试卷分析规范

## Output

```text
high_school/化学/试卷解析/<试卷名称>解析.md
```

## Required Structure

```markdown
# 试卷名称解析

## 试卷信息
## 试卷结构与题型分布
## 整体表现
## 知识点与能力点分布
## 分题型解析
## 逐题解析
## 错题分类
## 失分原因分析
## 高价值题目
## 后续复习计划
## 需要进入错题本的题目
```

## Question Types

- 选择题、填空题、实验题、推断题、计算题、流程题。
- 离子反应、氧化还原、元素化合物、物质结构、化学实验、化学计量。

## Analysis Focus

- 方程式题检查物质、条件、配平、离子拆写、电荷和守恒。
- 实验题分析目的、装置、操作、现象、结论和误差。
- 推断题分析题眼、转化关系、特征现象。
- 计算题分析物质的量关系、守恒关系和单位。

## Follow-Up Routing

- 典型错题进入 `错题本/`。
- 离子反应、氧化还原等进入 `知识点专题/` 或 `方法总结/`。
- 同类实验题进入 `题库整理/`。
