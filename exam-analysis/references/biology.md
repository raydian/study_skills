# 生物试卷分析规范

## Output

```text
high_school/生物/试卷解析/<试卷名称>解析.md
```

## Required Structure

```markdown
# 试卷名称解析

## 试卷信息
## 试卷结构与题型分布
## 整体表现
## 知识点与能力点分布
## 分题型解析
## 逐题解析
## 错题分类
## 失分原因分析
## 高价值题目
## 后续复习计划
## 需要进入错题本的题目
```

## Question Types

- 选择题、填空题、实验题、图表题、遗传题、综合题。
- 细胞、代谢、遗传、稳态、生态、实验探究。

## Analysis Focus

- 概念题看边界和关键词。
- 图表题看变量、趋势、对照和结论。
- 实验题看自变量、因变量、无关变量、对照组和结论表达。
- 遗传题看亲本、配子、基因型、表现型和概率路径。

## Follow-Up Routing

- 遗传、实验等高价值错题进入 `错题本/`。
- 实验分析、遗传计算方法进入 `方法总结/`。
- 细胞结构、稳态调节等进入 `知识点专题/`。
