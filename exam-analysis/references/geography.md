# 地理试卷分析规范

## Output

```text
high_school/地理/试卷解析/<试卷名称>解析.md
```

## Required Structure

```markdown
# 试卷名称解析

## 试卷信息
## 试卷结构与题型分布
## 整体表现
## 知识点与能力点分布
## 分题型解析
## 逐题解析
## 错题分类
## 失分原因分析
## 高价值题目
## 后续复习计划
## 需要进入错题本的题目
```

## Question Types

- 选择题、地图题、图表题、区域综合题、区位分析题、措施评价题。
- 自然地理、人文地理、区域地理、资源环境与可持续发展。

## Analysis Focus

- 地图题看定位、方向、比例尺、图例、等值线。
- 图表题看变量、趋势、峰谷、对比和异常点。
- 区位题按自然、人文、市场、交通、政策、技术等维度分析。
- 综合题看材料提取、因果链和分点作答。

## Follow-Up Routing

- 地图图表错题进入 `错题本/`。
- 区位分析、综合题方法进入 `方法总结/`。
- 气候、水循环、区域发展等进入 `知识点专题/`。
