# 历史试卷分析规范

## Output

```text
high_school/历史/试卷解析/<试卷名称>解析.md
```

## Required Structure

```markdown
# 试卷名称解析

## 试卷信息
## 试卷结构与题型分布
## 整体表现
## 知识点与能力点分布
## 分题型解析
## 逐题解析
## 错题分类
## 失分原因分析
## 高价值题目
## 后续复习计划
## 需要进入错题本的题目
```

## Question Types

- 选择题、材料解析题、比较题、原因影响题、小论文题。
- 中国古代史、中国近现代史、世界史、制度史、经济史、思想文化史。

## Analysis Focus

- 选择题看时空定位、概念辨析、材料主旨和干扰项。
- 材料题看出处、立场、时间、关键词和设问角度。
- 原因影响题按政治、经济、社会、文化、国际背景分层。
- 小论文题看观点、史实、论证和结论。

## Follow-Up Routing

- 材料解读错题进入 `错题本/`。
- 史料题、小论文方法进入 `方法总结/`。
- 制度史、经济史等主题进入 `知识点专题/`。
