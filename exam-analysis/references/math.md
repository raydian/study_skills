# 数学试卷分析规范

## Output

```text
high_school/数学/试卷解析/<试卷名称>解析.md
```

## Required Structure

```markdown
# 试卷名称解析

## 试卷信息
## 试卷结构与题型分布
## 整体表现
## 知识点与能力点分布
## 分题型解析
## 逐题解析
## 错题分类
## 失分原因分析
## 高价值题目
## 后续复习计划
## 需要进入错题本的题目
```

## Question Types

- 选择题、填空题、解答题、证明题、应用题、压轴题。
- 函数、不等式、三角、数列、立体几何、解析几何、概率统计、导数。

## Analysis Focus

- 统计概念题、计算题、证明题、综合题、压轴题得失分。
- 标出题目对应知识点、关键转化、方法入口和常见陷阱。
- 区分概念不清、条件漏读、计算失误、分类讨论不全、方法选择错误。

## Follow-Up Routing

- 反复错题进入 `错题本/`。
- 同类题集合进入 `题库整理/`。
- 函数审题、分类讨论等迁移方法进入 `方法总结/`。
