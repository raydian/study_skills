# 语文试卷分析规范

## Output

```text
high_school/语文/试卷解析/<试卷名称>解析.md
```

## Required Structure

```markdown
# 试卷名称解析

## 试卷信息
## 试卷结构与题型分布
## 整体表现
## 知识点与能力点分布
## 分题型解析
## 逐题解析
## 错题分类
## 失分原因分析
## 高价值题目
## 后续复习计划
## 需要进入错题本的题目
```

## Question Types

- 现代文阅读、文言文阅读、古诗词鉴赏。
- 名篇名句默写、语言文字运用。
- 作文、微写作、应用表达。

## Analysis Focus

- 阅读题看信息定位、概括能力、手法识别、主旨把握、答题术语和得分点。
- 文言文看实词虚词、句式、翻译采分点、人物事件理解。
- 诗歌看意象、情感、手法、炼字炼句。
- 作文看审题立意、结构、材料、语言、卷面和扣题程度。

## Follow-Up Routing

- 反复错的阅读题进入 `错题本/`。
- 可迁移答题流程进入 `方法总结/`。
- 文言实词、诗歌意象等进入 `知识点专题/`。
