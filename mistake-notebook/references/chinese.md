# 语文错题本规范

## Output

```text
high_school/语文/错题本/<错题主题>.md
```

## Required Structure

```markdown
# 错题主题

## 错题概览
## 题目形态归纳
## 错因统计
## 易错知识点
## 错题列表
## 二次订正
## 复习提醒
```

## Single Mistake Structure

```markdown
### 错题 1

- 来源：
- 日期：
- 题目形态：
- 知识点：
- 错因类型：
- 掌握状态：

#### 原题
#### 我的错误答案或错误思路
#### 正确解法
#### 错因分析
#### 防错提醒
#### 同类变式
#### 二次订正记录
```

## Subject-Specific Mistake Causes

- 审题偏差、概括不全、主旨误判。
- 表达手法混淆、答题角度遗漏、术语使用不准。
- 文言实词虚词误判、特殊句式未识别、翻译漏补。
- 诗歌情感判断错误、意象解读过度。
- 作文审题偏题、论证材料不贴切、结构松散。

## Requirements

- Preserve the original prompt and student answer when available.
- Explain scoring points and answer wording problems.
- Add a prevention rule that can be used before submitting a similar answer.
