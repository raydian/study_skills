# 数学错题体系：规划、整理与创建

## 目标与默认约定

输入一张 Markdown 数学试卷和错题号，创建可追溯、能读懂、可复习且能持续积累的错题体系。默认一个学生；按实际题目识别年级、章节，不猜教材版本。不需要学生先解释自己为什么错，也不把常见陷阱当作个人错因。

首次执行即完成本次题目的提取、讲解、巩固安排和索引创建，不只交一份空规划。没有提供真实试卷时，不虚构学生错题或生成学习档案。

## 一、定位并保留原题

1. 读取源 Markdown，识别题号所在的标题、列表或正文，区别原题区与答案区。支持 `3、7、12（2）、18`、`12(2)`、`第12题第2问` 等表达；归一化小问写法后去重。裸题号指整题，指定小问只收录该小问及必要上下文；整题和其小问同时出现时合并成整题记录。
2. 同一卷不同分区重复编号时，用“分区＋大题号＋小问号”定位；不能唯一定位则列出候选并请求确认。题号不存在时记入试卷处理清单，不编造原题。空题号列表不自动收录整卷。
3. 按原文保留题干、选项、数学符号、图表、题图、共用条件和被选中的小问。依赖前一小问时，保留必要题干并在解析中补充依赖结论，不把前一问登记为错题。源文“略”“见图”但图缺失等情况应明确指出。
4. 原题与讲解分开；疑似原文笔误保留原样，另注疑点。只有缺失信息确实不影响求解时，才在说明局限后继续；否则保留原题、标记待补材料，暂停确定性解答和变式推演，继续处理其他题。
5. 将源 Markdown 的相对图片地址解析到原文件位置，再在输出中重写为有效相对路径，或复制必要图片到该卷 `images/`；不移动、覆盖源图，不下载远程图绕过访问限制。记录源文标题路径或行号，便于回看。源文带参考答案时，将它与原题区分。

## 二、组织方式与稳定标识

```text
high_school/数学/错题本/
├── 错题总览.md
├── 试卷/
│   └── <试卷ID>/
│       ├── 试卷索引.md
│       ├── 题目/
│       │   ├── q003.md
│       │   └── q012-02.md
│       └── images/                 # 仅复制题图时创建
├── 按知识点/
│   └── <知识点>.md
└── 按题型/
    └── <解题任务型>.md
```

- **单题档案是唯一正文**；试卷、知识点、题型索引只放链接、简短训练目标和状态，不复制解析。未找到的题号仅留在处理清单，不建立空单题档案。
- 试卷ID优先采用源文已有的唯一标识或已登记的来源映射。首次无标识时，用规范化后的源文件绝对路径计算 SHA-256，取前12位并加 `paper-` 前缀；索引中保存原始来源路径和试卷标题，发生碰撞则延长哈希。更新内容不改变ID。
- 错题ID为 `<试卷ID>:<分区及归一化题号>`，文件名对应题号；不同分区用稳定前缀区分，例如 `s02-q003.md`。标题、日期和知识点不是唯一键。
- 文件搬迁后先核对原索引、题干和试卷信息，再更新来源映射；同名卷、相似题或同题型不能自动合并。跨卷相同题保留各自来源记录并建立关联。
- 对同卷同题再次输入，在原档案中更新或补充；不重复计数、不重置复测、不覆盖学生原始作答。若已有小问档案，后来改为整题整理，沿用已有档案并补齐范围、调整索引，不留下重叠的权威正文；有多份小问档案时合并保留各自历史，并修复旧链接。
- 旧格式 `<错题主题>.md` 中若已有同题，优先链接到已有题目锚点并按本规范补齐；不自动拆散旧文件。扫描相关旧记录后才创建新档案。
- 索引使用有效的 Markdown 相对链接；可补充已有学习笔记的 Wikilink，但先确认目标存在。文件名过滤路径分隔符等无效字符，标签和名称沿用已有数学笔记用语。

## 三、分类与讲解标准

### 分类要能指导复习

每题记录以下维度，主知识点与主题型各选一个，其余列为辅助：

| 维度 | 内容示例 | 用途 |
| --- | --- | --- |
| 知识点 | 分式分母非零、偶次根式非负、对数真数与底数条件 | 明确需补的概念和条件 |
| 题目形式 | 选择、填空、解答、证明、应用 | 保留卷面形式 |
| 解题任务型 | 复合式定义域求交集、含参数不等式分类讨论 | 组织同类训练，不能只写“函数题” |
| 核心方法 | 条件转化、数形结合、分类讨论、换元 | 说明解决此任务的具体工具 |
| 个人错因 | 已有作答支持的诊断，或“待确认” | 避免把题目难点当作个人事实 |

知识点写清“是什么、成立条件、在本题哪里使用”；题型写“题目要求完成什么任务”；思路写“为什么先做这一步”；方法写“具体怎么做、适用条件及局限”。四者不能用同一句套话代替。

### 从浅入深的讲解顺序

1. **读懂题意**：用日常语言说明给了什么、要求什么；解释关键符号，把条件与目标列清楚，不改变原题。
2. **补齐基础**：只补本题必要的概念、公式及适用条件。抽象处可用一个简单例子辅助，随后回到本题。
3. **辨认题型**：指出题干中触发某种处理方式的具体特征。例如“分母含未知数”提示检查非零条件，而非只说“套定义域公式”。
4. **分析突破口**：从目标倒推需要什么，再把已知转成可用条件。解释为什么选择该方法、先后顺序以及关键转折；适用时说明一个常见走不通的方向。
5. **分步解答**：给出完整可核验的数学过程。每个关键步骤配“做什么＋为什么”；常规运算可合并，关键等价变形、分情况依据和证明理由不能跳过。
6. **检查结果**：回查定义域、参数取值、端点开闭、增根漏解、符号和分类是否穷尽；按本题实际需要选择。给出明确答案和必要的答题格式。
7. **提炼可迁移方法**：用简短步骤说明下次看到哪些特征时如何行动，并写明方法的适用范围；不要把本题数字运算照抄成通法。

优先讲透一条适合当前学习阶段的解法；只有另一方法能帮助理解关键差异时才增加对照。少用“显然、易得”跨过学生需要理解的步骤，避免用超纲技巧替代基础讲解。

### 错因依据

有学生作答时，先如实保留答案或过程，找到最早可证实的偏离步骤，说明错误规则、影响及改正办法；证据不足则指出还需确认什么。可选类别包括概念条件遗漏、定义域忽略、分类不全、非等价变形、符号或范围错误、计算错误、图形关系误判、证明缺少依据、概率事件划分错误。

没有学生作答时写“未提供；个人错因待确认”，仅给针对本题的常见易错点和可选诊断自问，例如“是否同时写出了根式和分母的限制？”不能写“你忘记了检查分母”。错因统计只统计有证据的类别，未知单列，不从题型推断个人薄弱项。

## 四、巩固规划与掌握验证

每题形成具体的“补知识 → 练同型 → 做迁移 → 延后复测”安排。把“本题要求掌握”与“已证实的个人薄弱点”区分；没有学生证据时，训练计划是基于题目的建议。

| 层次 | 必须交代 | 验收方式 |
| --- | --- | --- |
| 基础知识 | 需巩固的概念、条件、与原题的联系；如何回顾或口述 | 不看解析说清条件，能用简单例子辨别适用性 |
| 同型训练 | 与原题相同的任务型、需重复练习的关键步骤 | 独立完成，条件和推理完整，能解释关键一步 |
| 迁移训练 | 改变条件、问法或表示方式，检验方法边界 | 能识别变化并调整方法，不依赖背原题答案 |
| 延后复测 | 复测目标、建议时点、记录方式 | 隔一段时间独立作答并说明理由，记录真实结果 |

- 材料完整且能确定求解的题目，默认每题配 **1道基础巩固题＋1道同型变式题**；确有迁移价值再加1道迁移题。待补材料的题目先说明阻塞点与补齐后的训练目标，暂不生成依赖缺失条件的练习。少量练习围绕该错题，不扩展成整章题库；相同训练目标可跨题共享，用链接引用。
- 原创题标明“原创巩固题”，已有题注明真实来源。每题都有训练目标、题干及核验过的答案与解析；题目先展示，答案放 Markdown `<details>` 折叠块，避免复习时直接看到答案。不能只改数字却声称检验迁移能力。
- 根据真实薄弱点安排优先级；未知时按先修关系给建议并说明依据。可以建议首次订正后次日同型训练、约一周后复测，但没有订正日期就不填实际日历日期。这些是建议，不自动创建提醒或定时任务。
- 状态取 `待补材料 / 待订正 / 待复测 / 复测通过 / 需再巩固`。材料完整且只有错题号时默认“待订正”；生成了解析不等于学生已订正。收到学生独立订正结果后再记“待复测”；收到独立复测的实际作答或明确结果反馈后才记“复测通过”。再次做错则记“需再巩固”。
- 复测记录追加日期（未给出则记未提供）、题目或来源、是否看提示、作答证据或用户反馈、结果和下一步。自述做对可记为“用户自报”，不伪装成已检查完整过程；只看答案、做题次数或时间流逝不能作为通过证据。

## 五、单题档案模板

以下各节是内容契约：填入本题具体讲解，不输出只有标题的空表。未知信息明确标注，不能为了填满字段虚构事实。待补材料时，在相关节说明无法完成的原因与需要补充的材料，不强行生成确定性解答或练习。

```markdown
---
错题ID: "<试卷ID>:<归一化题号>"
学科: 数学
试卷ID: "<试卷ID>"
原题号: "12（2）"
来源: "<源 Markdown 路径>"
来源定位: "<标题路径或行号>"
主知识点: "<名称>"
辅助知识点: []
题目形式: "<选择/填空/解答等>"
主题型: "<具体解题任务型>"
核心方法: []
错因状态: 待确认
掌握状态: 待订正
---

# 第12题（2）｜<简短任务说明>

## 原题
原文题干、共用条件、所选小问、选项及必要题图。

## 读懂题意
通俗解释；已知条件；目标；关键符号。

## 本题知识点与题型
必要知识的含义和适用条件；各知识在本题中的作用；辨认题型的线索。

## 分析与解题思路
目标倒推、条件转化、突破口、方法选择及其理由。

## 分步解答与结果检查
逐步说明做什么及为什么；明确答案；检查条件和边界。
注明答案依据：独立推导 / 参考答案并已核验 / 存在待确认冲突。

## 可复用的答题方法
识别特征 → 操作步骤 → 检查要点；适用条件及边界。

## 我的作答与错因
如实保留已提供内容；未提供则明确标记。区分已证实错因与常见易错点。
给出与具体步骤对应的防错动作。

## 后续巩固计划
列出知识点、题型、巩固方法、训练先后和验收标准；链接可用的学习笔记。

## 分层巩固练习
基础题、同型变式及各自目标；必要时迁移题。
每道题的答案与解析分别放入 details 折叠块。

## 订正与复测记录
无实际记录时写“尚未提供订正或复测结果”。以后按证据追加，不预填通过。
```

## 六、索引与执行验收

- **试卷索引**：源路径、试卷ID、标题、用户请求题号、归一化题号、定位结果、每题档案链接、主知识点、主题型、当前状态和下一步。明确列出缺题、歧义或缺图。
- **知识点索引**：简短概念说明、关联错题链接、每题训练目标和状态；按先修知识组织。对真实出现的知识点建索引，不预建空目录树。
- **题型索引**：识别线索、关联错题链接、各题的关键差异和训练重点；只汇总本次错题支持的内容。
- **错题总览**：试卷入口、知识点和题型入口、待处理问题与下一步复习。统计以唯一错题ID为准，明确整题/小问的计数口径；知识点归属次数不当作独立错题数。错因未知单列，学生学习日期与档案生成日期分开。
- 每次更新同步受影响索引与状态，保留未涉及的历史题目；不以新卷覆盖旧卷。

交付前逐项核对：

1. 请求题号全部有定位结果，完整原题与源文一致，题图和公共条件可追溯。
2. 每题均有具体知识点、任务型、通俗题意、思路理由、逐步解答、结果核验和可迁移方法。
3. 原题与自编练习均验证运算、定义域、参数条件、逻辑和答案；参考答案冲突单列。涉及对数等条件不完整时，不擅自增加条件给出唯一结论。
4. 每题巩固内容明确“补什么、练哪类、如何练、怎样算会”，答案可折叠。
5. 错因、订正和掌握状态都有证据或明确待确认；没有虚构成绩和个人作答。
6. 同卷重跑不新增重复档案或重置状态，跨卷索引保留历史，内部和来源链接可用。

向用户返回错题总览与本卷索引的链接，概述新增/更新/待确认数量和建议先做的巩固任务。不要声称已跑过真实试卷或学生已经掌握，除非有对应证据。
