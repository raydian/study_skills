# 化学错题本规范

## Output

```text
high_school/化学/错题本/<错题主题>.md
```

## Required Structure

```markdown
# 错题主题

## 错题概览
## 题目形态归纳
## 错因统计
## 易错知识点
## 错题列表
## 二次订正
## 复习提醒
```

## Single Mistake Structure

```markdown
### 错题 1

- 来源：
- 日期：
- 题目形态：
- 知识点：
- 错因类型：
- 掌握状态：

#### 原题
#### 我的错误答案或错误思路
#### 正确解法
#### 错因分析
#### 防错提醒

```

## Subject-Specific Mistake Causes

- 物质类别判断错误、反应条件遗漏、现象记忆混淆。
- 离子方程式拆写错误、离子共存条件漏判。
- 化合价判断错误、氧化还原电子转移错误。
- 物质的量计算关系错、守恒关系漏用。
- 实验操作顺序、试剂选择、现象解释错误。

## Requirements

- Include equations with Markdown/LaTeX when relevant.
- Explain "现象 -> 微观粒子 -> 方程式 -> 结论".
- Prevention rules should include condition, conservation, and charge checks.
