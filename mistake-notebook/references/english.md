# 英语错题本规范

## Output

```text
high_school/英语/错题本/<错题主题>.md
```

## Required Structure

```markdown
# 错题主题

## 错题概览
## 题目形态归纳
## 错因统计
## 易错知识点
## 错题列表
## 二次订正
## 复习提醒
```

## Single Mistake Structure

```markdown
### 错题 1

- 来源：
- 日期：
- 题目形态：
- 知识点：
- 错因类型：
- 掌握状态：

#### 原题
#### 我的错误答案或错误思路
#### 正确解法
#### 错因分析
#### 防错提醒
#### 同类变式
#### 二次订正记录
```

## Subject-Specific Mistake Causes

- 单词拼写、词性、搭配、熟词生义错误。
- 时态语态、非谓语、从句、主谓一致错误。
- 阅读定位错误、推断过度、干扰项识别失败。
- 完形上下文逻辑误判、语法填空结构判断错误。
- 写作表达中式英语、句子残缺、衔接不自然。

## Requirements

- Keep English source sentences and explain in Chinese.
- For reading mistakes, cite evidence from the text.
- For writing mistakes, provide a corrected expression and an upgraded expression when useful.
