# 历史错题本规范

## Output

```text
high_school/历史/错题本/<错题主题>.md
```

## Required Structure

```markdown
# 错题主题

## 错题概览
## 题目形态归纳
## 错因统计
## 易错知识点
## 错题列表
## 二次订正
## 复习提醒
```

## Single Mistake Structure

```markdown
### 错题 1

- 来源：
- 日期：
- 题目形态：
- 知识点：
- 错因类型：
- 掌握状态：

#### 原题
#### 我的错误答案或错误思路
#### 正确解法
#### 错因分析
#### 防错提醒
#### 同类变式
#### 二次订正记录
```

## Subject-Specific Mistake Causes

- 时空定位错误、阶段特征混淆。
- 材料主旨概括不准、史料立场忽略。
- 原因影响维度不全、比较对象不清。
- 史实与历史解释混淆、评价语言空泛。
- 小论文观点不明确、史论结合不足。

## Requirements

- Preserve source material and question stem.
- Explain which evidence supports the correct answer.
- Prevention rules should include time, space, source, standpoint, and context checks.
