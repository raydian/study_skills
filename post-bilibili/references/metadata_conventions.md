# 元数据生成约定（标题 / 标签 / 简介 / 封面）

本技能把"创意生成"交给 WorkBuddy（LLM），"机械投稿"交给 `scripts/publish.py`。
运行 publish.py 前，需先为每个视频准备好元数据，写入 `<目录>/bilibili-manifest.json`。
本文档规定元数据怎么写、封面怎么生成。

## 1. 清单文件格式

放在视频目录内，命名为 `bilibili-manifest.json`：

```json
{
  "tid": 201,
  "copyright": 1,
  "videos": [
    {
      "file": "高中数学必修一：指数函数-01-什么是指数函数｜知识点讲解.mp4",
      "title": "高中数学必修一：指数函数-01-什么是指数函数｜知识点讲解",
      "tags": ["高中数学", "指数函数", "高考数学", "函数概念"],
      "desc": "从「每次变为原来的 111%」出发，看懂固定倍率怎样推出 y=a^x……",
      "cover": "covers/01-什么是指数函数-cover.png"
    }
  ]
}
```

- `tid` / `copyright` 全局默认，单条可省略。
- `file` 为视频文件名（相对目录）。
- `cover` 可选；省略时 publish.py 会自动在 `covers/<名>.png`、`<名>.png` 等位置查找。
- 若不想写清单，publish.py 也支持**按文件名兜底**（标题=文件名，标签用 `--tags` 指定），
  但那只是应急，正式发布请用清单保证质量。

## 2. 标题

- **上限 80 字**（B 站硬限制，publish.py 会自动截断并提示）。
- 推荐结构（已在本项目验证）：
  `高中数学必修一：<章节>-<序号>-<主题>｜知识点讲解`
  例：`高中数学必修一：指数函数-01-什么是指数函数｜知识点讲解`
- 也可采用更"流量向"的结构（带栏目名与卖点）：
  `【高中数学】4.2 指数函数 第1讲·什么是指数函数 | 五讲重制版`
- 同一系列保持命名一致，便于观众识别与检索。

## 3. 标签

- 3–8 个，逗号分隔。既有"大词"也有"长尾词"：
  `["高中数学", "指数函数", "人教版", "高考数学", "函数概念", "数学笔记"]`
- 大词：学科、年级、教材版本、高考。长尾词：具体知识点、题型、方法。

## 4. 简介（desc）

- 纯文本，可换行。建议结构：
  ```
  本节内容：
  1. ……
  2. ……
  适用：高一 / 高考一轮复习
  资料：配套笔记见评论区
  ```
- 突出"本节解决什么问题""适合谁看"，不要堆砌。

## 5. 封面生成

封面优先级（由高到低，publish.py 的 `find_cover` 自动遵循）：

1. 清单里显式指定的 `cover` 路径；
2. 已存在的 `covers/<视频名>.png` / `<视频名>.png` 等；
3. 从视频提取的帧（见 5.1，**优先**）；
4. 以上都无，或提取的帧不含标题信息 → 用 ImageGen 生成（见 5.2）。

> **核心原则**：优先用视频自身的画面（第一帧 / 第二秒帧）作封面，既贴合内容又零成本；
> **只有当提取的帧没有标题信息时**，才调用 ImageGen 生成一张带标题的封面。

### 5.1 优先提取视频帧（推荐）

很多课程 / 讲书视频开头就是标题卡（片头），直接用画面当封面最自然。提取命令：

```bash
python3 <技能目录>/scripts/publish.py "<视频目录>" --extract-covers
```

- 该命令用 **ffmpeg** 抓取每支视频的：
  - **第一帧 @0s** → `covers/<名>.png`（默认封面，**优先**）；
  - **第二秒帧 @2s** → `covers/<名>_t2.png`（备选，用于第一帧是黑屏 / 无关画面时）。
- 已存在 `covers/<名>.png` 时默认跳过（不覆盖你手工做的封面）；加 `--force` 可重新提取。
- **ffmpeg 缺失时**：脚本会提示先 `brew install ffmpeg`；若不想装，直接走 5.2 用 ImageGen。
- 提取后**用 Read 工具查看** `covers/<名>.png`：
  - ✅ 画面含清晰标题文字（片头标题卡）→ 直接用，无需 ImageGen；
  - ❌ 画面是纯人脸 / 空白 / 无关镜头（无标题信息）→ 走 5.2 用 ImageGen 生成带标题封面，
    并保存为 `covers/<名>.png` **覆盖**，publish.py 后续会自动用到；
  - 若第一帧是黑屏，可把 `covers/<名>_t2.png` 复制为 `covers/<名>.png` 再判断。

### 5.2 用 ImageGen 生成带标题封面（无标题帧时兜底）

仅当①视频没有可用帧，或②提取的帧不含标题信息时，才用 WorkBuddy 内置 **ImageGen** 工具
生成，保存到 `covers/<视频名>.png`（publish.py 会自动识别）。生成要点：

- **尺寸**：B 站封面建议 1146×717（16:10）或 1920×1080。生成时指定宽屏比例。
- **构图**：大标题文字 + 核心图形/公式 + 统一品牌底色。文字要少而大，避免小字。
- **提示词模板**（文生图）：
  ```
  一张 YouTube/B 站风格的知识科普视频封面，深色科技蓝渐变背景，
  正中央用超大白色粗体中文写着「指数函数 第1讲：什么是指数函数」，
  下方一行小字「高中数学必修一 · 知识点讲解」，
  左侧放一个简洁的 y=a^x 指数曲线示意图，
  整体扁平化、高对比、留白充足，无杂乱元素
  ```
- **风格统一**：同一系列所有封面用相同底色、字体层级、版式，仅替换标题与核心图。
- 生成后如文字有瑕疵，可重新生成或后续用图像工具修正；封面只要清晰可读即可。

> 注意：封面文件用 PNG 最佳（B 站支持 PNG/JPG）。若视频项目本身由 Remotion 输出了封面
> （如 `covers/*.png`），优先直接用，不必再用 ImageGen 生成。
