# image-gen-multi Prompt 规范（prompt-guide.md）

面向多模型生图的统一 Prompt 组织方法、风格词库与尺寸/分辨率映射。

---

## 1. 五要素模板

好的图像描述 = **主体 + 场景 + 光线 + 风格 + 色调**：

```
{主体}，在{场景}，{光线}，{风格}，{色调}
```

示例：

- `一只柴犬（主体），在樱花树下（场景），柔和逆光（光线），日系摄影（风格），暖色调（色调）`
- `一位宇航员（主体），漂浮在星云中（场景），冷冽蓝光（光线），电影级科幻（风格），深蓝紫色调（色调）`

## 2. 风格词库

| 类别 | 关键词 |
|---|---|
| 绘画 | 水彩、油画、水墨、素描、铅笔稿、扁平插画、卡通、漫画 |
| 摄影 | 写实摄影、胶片感、日系、胶片颗粒、长曝光、微距、航拍 |
| 科幻 | 赛博朋克、蒸汽朋克、未来主义、机械感、霓虹 |
| 动漫 | 吉卜力、宫崎骏风、新海诚、日漫、美漫 |
| 商业 | 产品摄影、电商主图、UI 占位、海报、3D 渲染、C4D |
| 其他 | 像素风、剪纸、涂鸦、线条艺术、低多边形、玻璃拟态 |

## 3. 质量关键词（提升出图）

- 通用：`高质量、细节丰富、8k、锐利对焦`
- 摄影：`浅景深、bokeh、黄金时刻、体积光`
- 人像：`真实皮肤纹理、自然表情、专业打光`
- 避免：`低分辨率、模糊、变形、多余手指、文字乱码`（放入 negative-prompt）

## 4. 尺寸/比例映射

统一入口的 `--size` 接受两种形式，适配层换算到各渠道：

| 统一输入 | foxcode | bailian (bl) | volcengine (arkcli) |
|---|---|---|---|
| `1:1` | `1024x1024` | `1:1` 或 `1024*1024` | `--ratio 1:1` |
| `16:9` | `1536x1024` | `16:9` | `--ratio 16:9` |
| `9:16` | `1024x1536` | `9:16` | `--ratio 9:16` |
| `21:9` | `1792x768` | `21:9` | `--ratio 21:9` |
| `3:4` | `1152x1536` | `3:4` | `--ratio 3:4` |
| `2K` | 渠道支持时 | `2048*2048` 等 | `--resolution 2k` |

> 说明：foxcode 的 gpt-image 系列用像素尺寸（OpenAI 约定）；若用 gemini-flash-image 系列，
> 模型 ID 本身含比例后缀（如 `gemini-3.1-flash-image-2k-16x9`），此时直接选对应模型 ID 即可。

## 5. 渠道差异提示

- **foxcode gpt-image-2**：对中文 prompt 支持好，但生成慢（~60s）；`quality=low` 可加速降成本。
- **bailian qwen-image-3.0**：默认 `--watermark true`，商用图记得 `--watermark false`；支持 `--negative-prompt`。
- **volcengine Seedream**：自然语言入口，prompt 可更口语化；支持服务端 `--optimize-prompt`。
- 多模型生成风格一致性：固定 `--seed`，同一渠道同一模型重复生成可复现（渠道支持时）。
