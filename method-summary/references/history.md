# 历史方法总结规范

## Output

```text
high_school/历史/方法总结/<方法名称>.md
```

## Required Structure

```markdown
# 方法名称

## 来源题目概览
## 题目形态归纳
## 方法分类归纳
## 适用场景
## 方法核心
## 操作步骤
## 判断依据
## 示例演示
## 常见变形
## 易错提醒
## 训练建议
## 速查清单
```

## Method Types

- 史料阅读、材料概括、观点提炼。
- 原因背景题、影响意义题、变化趋势题。
- 中外比较题、阶段特征题。
- 历史解释、史论结合、小论文题。

## Requirements

- Classify input questions by problem form before summarizing methods.
- Classify input questions by solving method or analysis method, then summarize each reusable method.
- `题目形态归纳` should describe visible question forms such as material type, chart/diagram/table, experiment, calculation, proof, reading passage, multiple-choice, short-answer, essay, or comprehensive task.
- `方法分类归纳` should group questions by shared thinking path, not by source order.
- Explain how to use time, space, source author, standpoint, and context.
- Build answer dimensions: politics, economy, society, culture, international context.
- Distinguish source information from textbook knowledge and historical interpretation.
- Include concise scoring-language examples.
