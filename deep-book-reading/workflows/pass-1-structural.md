# PASS 1 — Structural reading

## Goal

Build a provisional map without pretending to have completed analytical reading.

## Procedure

1. Read title pages, contents, preface/introduction, chapter openings/closings, index, bibliography structure, and visual overview pages.
2. State the book's apparent central question and provisional thesis, each with source references.
3. Classify chapter roles: setup, definition, mechanism, evidence, application, revision, objection, synthesis, or conclusion.
4. Map dependencies: which concepts and claims must be understood before later chapters.
5. Create provisional concept and argument maps. Label all as provisional.
6. Allocate stable IDs to recovered source units. Preserve printed and file page locators.
7. Update the Reading Ledger and `synthesis/book-map.md`.

## Exit gate

Every chapter and structural component has an ID, role, page range, and reading order. Provisional claims are not promoted to final knowledge units until PASS 2 verifies them in context.
