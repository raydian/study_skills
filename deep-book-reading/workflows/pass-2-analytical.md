# PASS 2 — Analytical chapter reading

Process one chapter at a time as a resumable atomic package.

## Per-chapter sequence

1. Normalize Source in staging: restore structure and stable locators while preserving wording.
2. Compare risky and sampled units with the original; seal and hash the chapter Source.
3. Read every section and resource. Record open OCR or interpretation issues in the Reading Ledger.
4. Extract the chapter question, answer, concepts, claims, argument chain, evidence, cases, methods, frameworks, counterexamples, and limitations.
5. Add evidence and claim relationships to the Evidence Ledger before drafting conclusions.
6. Write the main guided-reading article using the chapter workflow.
7. Score density using five 0–20 dimensions: independent concept clusters, argument branches, reusable frameworks/methods, distinct applications/cases, and cross-chapter importance. Record the score and evidence.
8. Apply plan B: `<60` main only; `60–74` main + 2 topics; `75–89` main + 3; `90–100` main + 4. Topic readings require distinct reader questions and primary source ranges.
9. Create annotated Markdown, structured annotations, and canonical knowledge units.
10. Run traceability, attribution, resource coverage, and fidelity checks; update checkpoint state.

## Chapter completion

A chapter is complete only when its mandatory resources are reviewed or classified, every material derived claim is traceable, the main reading exists, and no high-impact fidelity issue remains.
