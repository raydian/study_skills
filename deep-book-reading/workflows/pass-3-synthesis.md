# PASS 3 — Cross-chapter synthesis

## Procedure

1. Re-read chapter cards, ledgers, high-importance Source units, and all unresolved cross-chapter links.
2. For every important concept, record initial definition, extensions, constraints, revisions, contradictions, and final state with chapter/source refs.
3. Build an argument graph: question → reasons/mechanisms → claims → evidence/cases → counterarguments → limitations → conclusions.
4. Identify reused evidence, circular support, apparent conflicts, and changes in terminology.
5. Distinguish author-system synthesis (`ai_synthesis`) from explicit author statements.
6. Produce the required synthesis files and update global knowledge indexes.

## Exit gate

Later revisions override earlier operational use while earlier states remain in the evolution history. Conflicts remain visible. The full-book model explains relationships and hierarchy rather than listing chapter summaries.
