# PASS 0 — Survey and intake

## Entry

At least one source file or complete chapter collection is available.

## Procedure

1. Record title, author, edition, language, publication metadata, file format, authorization basis, and file identity in the Book Manifest.
2. Compare file page count, printed pagination, table of contents, front/back matter, appendices, notes, bibliography, and index. Record missing, duplicate, blank, rotated, or corrupt pages.
3. Determine searchable text versus scan. Sample front, middle, and back pages for extraction/OCR quality.
4. Inventory chapters, sections, paragraphs, figures, tables, equations, code blocks, footnotes/endnotes, sidebars, captions, and appendices.
5. Select a primary reading profile and optional secondary profile.
6. Create Reading Ledger totals, PASS states, known gaps, and first resumable unit.
7. Create an empty Evidence Ledger using the reference schema.

## Exit gate

Pass only when the received object is unambiguously described, authorization is recorded, page mapping is known, and missing content is classified. An incomplete source may proceed for partial work but cannot reach final whole-book status.
