# Book profile classifier

Choose the profile by the book's dominant reasoning object, not its marketing category.

| Signal | Primary profile |
|---|---|
| principles → architecture → implementation → code | technical |
| prerequisite concepts → formal statements → examples/exercises | textbook |
| problem → framework → method → case → boundary | business-management |
| research question → method → evidence → inference | academic |
| chronology → actors → decisions → causes → consequences | history-biography |
| character/form/voice → plot → imagery → theme | literature |

Use one primary and at most one secondary profile unless the book is an explicit anthology. Record uncertainty and reclassify after PASS 1 if the evidence changes. Profile choice changes emphasis, not core provenance, coverage, or Source integrity rules.
